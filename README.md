# BookBot — бот-рекомендатель книг

BookBot — чат-бот, который поможет выбрать книгу для чтения.

### Как это работает для пользователя:
1. Бот задаёт вам 3 вопроса о ваших предпочтениях (жанр, сложность, объём).
2. Вы отвечаете на каждый вопрос, вводя один из предложенных вариантов.
3. Бот анализирует ваши ответы и выдаёт список из нескольких книг, которые подходят вам лучше всего.

### Основные возможности
**Умный подбор:** алгоритм ищет книги, которые совпадают с ответами пользователя по ключевым параметрам.
**Сброс опроса:** в любой момент можно очистить текущие ответы и начать подбор заново.

## Domain

**1. class Book**
Описывает сущность книги, доступной для рекомендации. Содержит поля title, author, tags (характеристики книги), конструктор для инициализации полей и стандартные геттеры.

**2. class Question**
Описывает сущность вопрос. Содержит поля key (идентификатор темы вопроса), text (текст вопроса), options (список доступных вариантов ответа). Методы: геттеры для полей, isValidAnswer(String answer) — проверяет, содержится ли переданная строка в списке options.

**3. class Quiz**
Представляет собой сессию прохождения опроса и управляет её состоянием.
Хранит список вопросов (List<Question> collection), словарь для записи ответов (Map<String, String> answer, где ключом выступает идентификатор вопроса) и числовой индекс текущего вопроса (current_idx). Логика работы: метод isFinished() проверяет, не вышли ли мы за пределы списка вопросов; метод getCurrentQuestion() возвращает текущий вопрос или null, если опрос завершён; метод safeAnswer() принимает вопрос и ответ пользователя, проверяет валидность ответа (с помощью Question.isValidAnswer), при успехе сохраняет пару «ключ-ответ» в Map и инкрементирует индекс, при невалидном ответе выбрасывает IllegalArgumentException; метод getAnswers() возвращает карту ответов только после успешного завершения опроса.

**4. class Recommender**
Доменный сервис – алгоритм подбора книг на основе ответов пользователя. Содержит константы (минимальное число совпадений – MIN_MATCH, максимальное число рекомендаций – TOP_LIMIT), поле books (база книг для поиска). Методы: countMatches - вычисляет релевантность. Проходит по всем ответам пользователя и сравнивает их с тегами книги. Возвращает количество совпадений; recommend – фильтрует список книг, оставляя только те, у которых количество совпадений тегов с ответами пользователя больше или равно MIN_MATCH, затем сортирует результат по убыванию совпадений и обрезает список до TOP_LIMIT.

**5. class SampleBook**
Утилитарный класс для предоставления статического набора данных. Имеет приватный конструктор, метод all() – возвращает список книг.

## Infrastructure

**class InMemoryStorage**
Класс, реализующий интерфейс QuizStateStorage (implements QuizStateStorage).
Хранит состояние текущей сессии опроса в оперативной памяти. Методы: save(Quiz quiz) — перезаписывает внутреннее поле класса переданным объектом; get() — возвращает текущий сохраненный объект опроса (или null, если его нет); delete() — обнуляет переменную (null), тем самым удаляя сессию из памяти.

## Application

**1. interface QuizStateStorage**
Интерфейс для сохранения и извлечения текущей сессии опроса.

**2. class QuestionData**
“Копия” сущности Question для отображения в пользовательском интерфейсе. Содержит text, options, не содержит поля key в отличие от доменной сущности Question.

**3. class StartQuiz**
Класс, запускающий новый цикл опроса. Метод run() - создает новый экземпляр доменной сущности Quiz (в которой уже инициализирован список вопросов), сохраняет созданный опрос в хранилище через вызов storage.save(quiz), запрашивает у объекта Quiz первый текущий вопрос, оборачивает полученный вопрос в QuestionData для безопасной передачи в слой Presentation, возвращает QuestionData.

**4. class AnswerQuestion**
Класс, обрабатывающий ответ пользователя на текущий вопрос. Зависимости: QuizStateStorage (для получения/сохранения состояния опроса) и Recommender (для подбора книг в конце). На вход получает строку с выбранным вариантом ответа (String answer), на выходе AnswerResult (полиморфный тип, может быть NextQuestionResult или RecommendationResult). Алгоритм работы: извлекает текущий объект Quiz из хранилища, если опрос не найден, выбрасывает IllegalStateException.
Передает ответ пользователя в доменную сущность Quiz методом safeAnswer(), сохраняет обновленное состояние Quiz обратно в хранилище. Если опрос не завершен, извлекает следующий вопрос, оборачивает его в QuestionData, затем в NextQuestionResult и возвращает. Если опрос завершен, извлекает все ответы пользователя. Передает их в Recommender.recommend() для получения списка книг (List<Book>). Оборачивает каждую сущность Book в BookData (извлекая только название и автора). Формирует RecommendationData, оборачивает в RecommendationResult и возвращает.

**5. class AnswerResult**
Абстрактный класс для всевозможных сценариев ответа на вопрос.

**6. class NextQuestionResult**
Наследник AnswerResult, представляет результат, когда опрос еще не завершен. Содержит единственное поле question типа QuestionData. Предоставляет геттер для получения следующего вопроса.

**7. class RecommendationResult**
Наследник AnswerResult. Представляет результат, когда опрос завершен и сформирован список рекомендаций. Содержит единственное поле recommendation типа RecommendationData (внутри которого лежит список книг). Предоставляет геттер для извлечения рекомендаций.

**8. class BookData**
«Копия» одной книги для отображения в интерфейсе. В отличие от доменной сущности Book, этот класс не содержит тегов и описания, содержит только title и author.

**9. class RecommendationData**
Хранит внутри себя List<BookData> books – список рекомендованных книг.

**10. class ResetQuiz**
Класс, сбрасывающий текущий опрос. Принимает через конструктор QuizStateStorage. Метод run() выполняет единственное действие — вызывает storage.delete().
